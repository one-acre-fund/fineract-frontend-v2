Feature Flag POC: Clients KYC V2 Demo route protected by the {{ flagName }} runtime flag. {{ flagName }} = true

You can see this page because the environment enabled the demo flag. If {{ flagName }} is false, this route is blocked and the Home page button is hidden.

  1. Merge the feature branch into develop.
  2. Deploy the same build to Test/QA/UAT.
  3. Set FEATURE_FLAGS=clients.kyc-v2=false to hide this feature.
  4. Set FEATURE_FLAGS=clients.kyc-v2=true to show this feature.

This is a frontend release-control POC. Backend-sensitive behavior still needs backend enforcement.
